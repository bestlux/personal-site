# Product Specification: iomancer

## Product Intent
`iomancer` is a personal living hub: a single place for projects, writing, resume context, and a regularly updated "now" snapshot. The site should feel like an invitation into an active technical mind, not a static brochure.

## Audience
Primary audience: peers, builders, and curious visitors.
Secondary audience: potential collaborators, contract clients, and hiring decision-makers.

## Core Outcomes
- Present a coherent identity without exposing personal legal identity.
- Showcase projects with enough context to prove capability.
- Publish writing and ideas with an opinionated technical voice.
- Provide a contact path with anti-scrape protections.

## Launch Scope (v1)
- Home hub
- Projects index + project detail pages
- Writing index + post detail pages + tag archive
- Now page
- Resume page + downloadable PDF
- Contact page
- Privacy page
- Colophon page
- RSS feed, sitemap, robots, metadata/OG support
