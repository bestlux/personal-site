# Decision Log

- **Identity**: Alias-only brand (`iomancer`) with high privacy.
- **IA**: Hub + Streams model (projects, writing, now, resume, contact).
- **Voice**: Thoughtful technical voice with reflective framing.
- **Visual Direction**: Retro-futurist terminal + selective cyberpunk neon accents.

- **Motion**: Intentional medium animation level.
- **Stack**: Next.js + TypeScript + Tailwind + MDX (lean, no DB/auth/tRPC in v1).

- **Analytics**: Privacy-first lightweight analytics target.
- **SEO**: Strong technical SEO (sitemap, robots, canonicals, OG, structured data).
- **Accessibility**: WCAG 2.2 AA target.
- **Testing**: Lint + typecheck + unit tests + Playwright smoke e2e.
- **Contact**: Obfuscated email + X + GitHub.
- **Publishing Workflow**: Git-based Markdown/MDX.
