# Domain Shortlist

## Recommended Purchase Order
1. `iomancer.dev`
2. `iomancer.net`
3. `lightweavelabs.dev`
4. `lightweavelabs.com`

## Rationale
- `iomancer.dev` matches alias branding and technical positioning.
- `.dev` reinforces builder identity and is generally expected for technical portfolios.
- `lightweavelabs.*` supports future studio/contract framing if you pivot harder toward services.

## DNS/Hosting Notes
- Point apex and `www` to Vercel.
- Set canonical domain to a single host.
- Ensure HTTPS and redirect consistency on launch.
