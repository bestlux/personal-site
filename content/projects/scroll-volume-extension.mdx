Scroll Volume is a browser quality-of-life tool built for fast, consistent media control.

## Core capabilities

- wheel-to-volume on hovered video elements
- multiple activation modes (hover, modifier, fullscreen, focused player)
- per-site allow/block behavior and overrides
- configurable HUD and wheel normalization for mouse and trackpad input

## Intent

I wanted a polished extension that behaves predictably on modern media-heavy sites without accidental capture.
