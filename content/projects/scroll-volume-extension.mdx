Scroll Volume is a browser quality-of-life tool built for fast, consistent media control.

## Goal

Build the exact scroll-volume extension I always wanted, using AI agents to accelerate development and iteration.

## Hardest challenge

Deciding when wheel input should control video volume versus when it should pass through to normal page scrolling while hovering media.

## Outcome

Published to both the Microsoft Edge Add-ons store and the Chrome Web Store.
